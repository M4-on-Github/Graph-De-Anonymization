# Dependencies

### For FLASK-API (backend) and graphing (research) scripts:
A python venv is required with the following installed via pip:
 - networkx
 - pytorch
 - numpy
 - matplotlib
 - flask
 - flask-cors

### For frontend 
Frontend is React + NPM based. The following packages are needed:
 - cytoscape (graph visualization, will need to install manually)
 - react
 - react-dom (for pages)
More info available in `frontend/package.json`
